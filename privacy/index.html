1. 基本方針

Watson US CPA（以下「当方」）は、業務上お預かりする個人情報の重要性を認識し、適用される法令およびガイドラインを遵守して、適切に取得・利用・管理します。

当方は米国公認会計士として税務業務を行うため、お客様の税務情報を取り扱います。これらの情報は、ご依頼いただいた業務の遂行のためにのみ使用し、法令に基づく場合を除き、ご本人の同意なく第三者に提供することはありません。

2. 取得する情報

2-1. フォームからご提供いただく情報

お問い合わせフォーム、お見積もりフォーム等でご入力いただいた、お名前、メールアドレス、会社名（法人のお見積もりの場合）、ご相談内容、およびお見積もりに必要な範囲の税務上の状況に関する情報を取得します。

また、ご相談日時の予約（Cal.com）の際にご入力いただいたお名前、メールアドレス、ご希望の日時等を取得します。

フォームの送信時点では、ソーシャルセキュリティナンバー（SSN）、口座番号等の機微な情報はご入力いただかないようお願いしています。業務に必要なこれらの情報は、ご契約後に安全な方法で別途お預かりします。

2-2. 判定ツールへの入力内容

本サイトの判定ツール（IRA判定、FBAR / FATCA チェック、お見積もりシミュレーター等）に入力された数値や選択内容は、お使いのブラウザ内でのみ処理され、当方のサーバーへ送信されることはありません。フォームから明示的に送信された場合に限り、当方に届きます。

2-3. アクセスに伴い自動的に取得される情報

本サイトの配信事業者において、アクセス日時、参照元、ブラウザの種類等の技術的な記録が保存される場合があります。これらはサイトの安定運用および不正アクセスの検知のために用いられます。

また、利用状況の把握のため、本サイトの各ページに Cloudflare Web Analytics の計測用スクリプトを設置しています。同サービスにより当方が確認できるのは、ページの表示回数、参照元、おおよその地域、ブラウザの種類、ページの表示速度といった集計情報です。同サービスは Cookie やブラウザのローカルストレージを使用せず、IP アドレス等を用いて個人を識別したり、サイトを横断して追跡したりすることはありません。

当方は、本サイトに広告目的のトラッキングを設置していません。

3. 利用目的

取得した情報は、次の目的の範囲内でのみ利用します。

  • お見積りのご提示およびご依頼に関するご連絡
  • ご契約いただいた税務業務の遂行
  • お問い合わせへの回答
  • 法令および税務当局の要請に基づく対応
  • 本サイトの運用・保守および品質向上

ご本人の同意なく、上記の範囲を超えて利用することはありません。

4. 第三者への提供

次の場合を除き、取得した情報を第三者に提供することはありません。

  • ご本人の同意がある場合
  • 法令に基づく場合、または税務当局・司法機関から適法な手続により開示を求められた場合
  • 人の生命、身体または財産の保護のために必要であり、ご本人の同意を得ることが困難な場合

業務の遂行にあたり外部の事業者に処理を委託する場合は、委託先に対して本ポリシーと同等の管理を求めます。

5. 外部サービスの利用

本サイトの運営にあたり、次の外部サービスを利用しています。各サービスにおける情報の取り扱いは、それぞれの提供事業者のプライバシーポリシーに従います。

  • Netlify（サイトのホスティング、およびフォーム送信内容の受付・保管）
  • Cal.com（ご相談日時の予約受付）
  • Cloudflare Web Analytics（利用状況の集計。Cookie 不使用）
  • Google Fonts、jsDelivr（Webフォント・アイコンの配信）

フォントやアイコンの配信にあたっては、ブラウザから各配信事業者のサーバーへ IP アドレス等の通信上必要な情報が送信されます。

また、本サイトから note、X（旧Twitter）、マシュマロ、YouTube 等の外部サイトへのリンクを掲載しています。リンク先における情報の取り扱いについては、当方は責任を負いかねます。各サイトのポリシーをご確認ください。

6. Google API を利用したサービスについて

当方は、自社で制作した動画コンテンツを当方自身が運営する YouTube チャンネルへ公開するための社内用ツールにおいて、YouTube Data API（Google API Services）を利用しています。

6-1. 取り扱う情報の範囲

当該ツールが取り扱うのは、当方自身の Google アカウントおよび YouTube チャンネルに関する情報のみです。具体的には、動画のアップロード権限、および投稿先チャンネルを確認するためのチャンネル名・チャンネルIDを参照します。

本サイトの閲覧者、お客様、その他第三者の Google アカウント情報を取得・保存・利用することは一切ありません。

6-2. 認証情報の管理

Google による認証で発行されたアクセストークンは、当方が管理する端末内にのみ保存し、外部に送信・共有することはありません。

6-3. Limited Use への準拠

Google API から取得した情報の使用および他アプリへの移転については、Google API Services User Data Policy（Limited Use requirements を含む）を遵守します。

当該情報を、広告目的で利用すること、第三者に販売・譲渡すること、および人間が閲覧することは、法令上必要な場合またはご本人の明示的な同意がある場合を除き、行いません。

7. 保管・安全管理と保存期間

お預かりした情報は、アクセス制限を施した環境で保管し、業務に必要な担当者のみが取り扱います。

米国の税務申告書の作成に関する記録（申告書の写し、またはお客様の氏名および納税者番号の一覧）は、米国内国歳入法第6107条(b)の定めに従い、当該申告期間の終了後少なくとも3年間保管します。その他の税務業務に関連する記録は、米国および日本の関係法令が定める保存期間、または業務上必要な期間保管します。

保存期間を経過し、かつ業務上保持する必要がなくなった情報は、適切な方法で廃棄します。

メールやフォームでのやり取りは、通信経路上の安全性を完全に保証できるものではありません。機微な情報のご提供は、ご契約後にご案内する安全な方法をご利用ください。

8. 開示・訂正・削除のご請求

ご自身の個人情報について、開示、訂正、利用停止または削除をご希望の場合は、下記の窓口までご連絡ください。ご本人であることを確認のうえ、法令に従い、合理的な期間内に対応します。

なお、法令により保存が義務付けられている記録については、保存期間中は削除に応じられない場合があります。
